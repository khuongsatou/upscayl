01. Tổng quan dự án

Upscayl là ứng dụng Electron + Next.js/React + TypeScript để nâng cấp ảnh bằng AI. App desktop chạy pipeline cục bộ qua binary upscayl-bin và các model NCNN .bin/.param.

02. Flow chính

Người dùng chọn ảnh/thư mục, model, scale, output và tùy chọn nâng cao.
Renderer gom state Jotai thành payload và gửi qua window.electron.send.
Electron main nhận IPC, chuẩn hóa path, chọn model path và build command arguments.
spawnUpscayl chạy upscayl-bin bằng Real-ESRGAN/NCNN Vulkan.
Electron nghe progress/error từ process rồi gửi event về renderer.
UI cập nhật progress, toast lỗi, notification, preview slider/lens hoặc nút mở folder.
LayerFile đại diệnVai trò

Bridgeelectron/preload.tsExpose API Electron cho renderer.
UIrenderer/pages/index.tsxState chính và event listener.
Commandelectron/commands/*upscayl.tsBuild path, spawn binary, gửi progress.

06. Prompt, command và model

Repo không có prompt LLM hoặc prompt text-to-image. “Prompt” của dự án là bộ tham số command-line điều khiển model upscale.

OptionÝ nghĩa
-iInput ảnh hoặc thư mục.
-oOutput file hoặc thư mục.
-mModel directory.
-nTên model.
-sScale nếu khác scale gốc của model.
-wChiều rộng output tùy chỉnh.
-f, -c, -g, -t, -xFormat, compression, GPU, tile size, TTA.
