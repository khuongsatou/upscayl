# Feedback Workflow

## Muc tieu

Thu muc `.feedback` la noi Codex, Antigravity, PM, QA, UX va Developer trao doi feedback theo luong ro rang: inbox -> response -> action plan.

## Cau truc file

| File | Purpose |
|---|---|
| `inbox.md` | Noi nhan feedback moi |
| `responses.md` | Noi PM/PO/Dev phan hoi Antigravity |
| `action-plan.md` | Noi chuyen feedback thanh task hanh dong |
| `qa_coverage.json` | Theo doi pham vi QA lien quan feedback |

## Quy trinh 4 buoc

1. Ghi feedback moi vao `inbox.md` voi ID dang `FB-YYYYMMDD-AREA-001`.
2. PM/PO/Dev danh gia feedback trong `responses.md`.
3. Neu Accept, tao task ro owner/ETA/status trong `action-plan.md`.
4. QA/UX verify, PM cap nhat ket qua va dong feedback.
