# Workflow: Release Readiness

## Muc tieu

Kiem tra san sang release desktop app tren cac nen tang.

## Buoc thuc hien

1. PM xac dinh pham vi release va rui ro.
2. DevOps chay typecheck/build phu hop.
3. QA test luong chinh va regression quan trong.
4. UX/Customer Reviewer duyet giao dien thay doi.
5. DevOps kiem tra artifact, config package, changelog.
6. PM viet `.manager/final_report.md`.

## Output

Release Go / No-Go.
