# Workflow: Model Runtime Maintenance

## Muc tieu

Bao tri model list, custom model, binary ncnn, scale check va runtime upscale.

## Buoc thuc hien

1. PM xac dinh runtime/model/platform bi anh huong.
2. Upscale Pipeline Specialist kiem tra model, scale, path, binary va command.
3. Developer sua contract/runtime neu can.
4. QA chay manual upscale flow voi input nho va duong dan co khoang trang.
5. DevOps kiem tra artifact lon khong bi commit nham.
6. PM ghi ket qua va known limitation.

## Output

Runtime/model on dinh hon va co test tai hien.
