# Workflow: Intake And Triage

## Muc tieu

Nhan task moi, lam ro muc tieu, gan owner va tao state ban dau.

## Buoc thuc hien

1. PM ghi `.manager/current_task.md`.
2. PO tach requirement va acceptance criteria vao `.manager/requirements.md`.
3. PM xac dinh skill/rule can kich hoat.
4. Neu task den tu feedback, lien ket Feedback ID trong `.feedback/action-plan.md`.
5. PM ket luan next action va owner.

## Output

Task san sang cho Developer/QA/UX.
