# Workflow: Performance Profiling

## Muc tieu

Tim va giam diem cham, treo UI, ton RAM/disk/GPU qua muc trong ung dung upscale.

## Buoc thuc hien

1. PM ghi metric can cai thien va scenario do.
2. Developer/QA tai hien voi anh mau, batch size, model va output folder.
3. Xac dinh bottleneck: renderer, IPC, file IO, process upscale, model loading.
4. Sua nho tung diem va do lai.
5. QA ghi before/after va residual risk.
6. PM ket luan co can lap tiep khong.

## Output

Bao cao metric va thay doi da verify.
