# Workflow: Dependency Upgrade

## Muc tieu

Nang cap package, Electron, Next.js, TypeScript hoac build tool co kiem soat.

## Buoc thuc hien

1. PM ghi package/version muc tieu va ly do.
2. Dev/DevOps doc changelog, breaking changes va scripts lien quan.
3. Nang cap toi thieu, giu lockfile nhat quan.
4. Chay typecheck/build/test phu hop.
5. QA kiem tra app launch va core upscale flow neu dependency cham runtime.
6. PM ghi risk va rollback note.

## Output

Dependency duoc cap nhat kem bang chung validation.
