# Workflow: Feedback Resolution

## Muc tieu

Xu ly feedback theo luong inbox -> response -> action plan.

## Buoc thuc hien

1. Them feedback vao `.feedback/inbox.md` voi ID `FB-YYYYMMDD-AREA-001`.
2. PM/PO danh gia trong `.feedback/responses.md`.
3. Neu Accept, tao task trong `.feedback/action-plan.md`.
4. Developer thuc hien va cap nhat `.manager/implementation.md`.
5. QA/UX xac minh, PM doi status Done.

## Output

Feedback co quyet dinh va hanh dong ro.
