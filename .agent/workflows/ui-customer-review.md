# Workflow: UI Customer Review

## Muc tieu

Lay goc nhin khach hang de danh gia giao dien va chuc nang truoc khi dong task UI.

## Buoc thuc hien

1. UX mo luong nguoi dung chinh va ghi an tuong dau tien.
2. Danh gia cac trang thai: empty, loading, success, error, disabled.
3. Cham diem UI 1-5 va Function 1-5.
4. Ghi finding vao `.manager/ux-feedback.md`.
5. Neu Needs Polish/Rejection, PM tao action trong `.feedback/action-plan.md` hoac lap iteration.

## Output

Customer verdict ro rang.
