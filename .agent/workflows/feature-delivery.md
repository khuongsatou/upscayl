# Workflow: Feature Delivery

## Muc tieu

Tu requirement den tinh nang hoan tat co test va customer review neu can.

## Buoc thuc hien

1. PO viet requirement va acceptance criteria.
2. Architect/Developer doc module lien quan.
3. Developer implement nho gon, ap dung Rule Splitting File neu file lon.
4. QA chay test/typecheck/build phu hop.
5. UX/Customer Reviewer danh gia UI/function neu nguoi dung thay duoc.
6. PM tong hop va ket luan.

## Output

Feature Done hoac danh sach viec can lap tiep.
