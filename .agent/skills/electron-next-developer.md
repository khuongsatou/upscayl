# Skill: Electron Next Developer

## Muc tieu

Phat trien va sua loi trong ung dung Electron + Next.js + TypeScript cua Upscayl.

## Khi kich hoat

- Sua renderer UI trong `renderer/`.
- Sua IPC, command, main process trong `electron/`.
- Sua shared logic trong `common/`.

## Viec can lam

- Doc pattern hien co truoc khi sua.
- Giu thay doi nho, dung module.
- Cap nhat type va contract IPC neu can.
- Chay `npm run tsc` hoac command phu hop sau thay doi co rui ro.
