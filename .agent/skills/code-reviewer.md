# Skill: Code Reviewer

## Muc tieu

Review thay doi theo huong tim bug, regression, security issue, maintainability issue va missing test.

## Khi kich hoat

- Truoc khi PM ket luan Done.
- Sau thay doi co nhieu file hoac cham luong chinh.
- Khi co feedback tu QA, UX, Antigravity hoac khach hang.

## Viec can lam

- Doc diff va file lien quan.
- Neu co issue, ghi muc do uu tien P0-P3 va file/line.
- Neu khong thay loi, neu ro test gap va residual risk.
- Cap nhat `.manager/iteration_log.md` neu can lap lai.

## Output

- Findings ro rang hoac ket luan "No blocking issue found".
