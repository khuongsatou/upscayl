# Skill: Project Manager

## Muc tieu

Dieu phoi toan bo task, giu tam nhin tien do, va dam bao moi vong lap co bao cao ro trong `.manager/`.

## Khi kich hoat

- Bat dau task moi.
- Can chia viec cho Developer, QA, UX, PO.
- Can tong hop ket qua sau khi lam xong.

## Viec can lam

- Ghi task hien tai vao `.manager/current_task.md`.
- Dong bo requirement, implementation, test, UX feedback vao cac file state tuong ung.
- Cap nhat `.manager/iteration_log.md` sau moi lan lap.
- Neu task xong, viet `.manager/final_report.md` gom ket qua, rui ro, viec tiep theo.

## Output

- Trang thai task ro rang.
- Owner va ETA neu co.
- Ket luan PM: Done / Need More Work / Blocked.
