# Rule: PM Approval Gate

## Bat buoc

Project Manager la nguoi ket luan task. Developer, QA va UX co the de xuat Done, nhung PM phai doc state trong `.manager/` truoc khi dong task.

## Dieu kien Done

- Requirement da co acceptance criteria.
- Implementation notes da ghi file thay doi.
- QA co ket qua hoac ly do khong chay duoc.
- Neu co UI/function, customer review da co verdict.
- Rui ro con lai duoc ghi ro.
