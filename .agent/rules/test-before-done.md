# Rule: Test Before Done

## Bat buoc

Khong ket luan Done neu chua co mot trong hai:

- Ket qua test/build/typecheck phu hop.
- Ghi chu ro vi sao khong the chay test va rui ro con lai.

## Goi y lenh

- `npm run tsc`
- `npm run build`
- `npm run validate-schema`
- Test thu cong luong upscale anh neu thay doi pipeline.
