# Rule: Performance And Resource Budget

## Muc tieu

Bao ve trai nghiem desktop khi xu ly anh lon, batch job, model va process GPU/CPU nang.

## Quy tac

- Task nang can co loading/progress/cancel neu phu hop voi UX hien co.
- Khong block renderer thread bang xu ly file/image nang.
- Theo doi memory, disk output va cleanup file tam khi sua pipeline.
- Feature moi khong duoc lam cham luong mo app/chon anh/upscale neu khong co ly do.
