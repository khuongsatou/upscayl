# Rule: Error Logging And Observability

## Muc tieu

Loi phai de tai hien va debug ma khong lam lo du lieu nhay cam.

## Quy tac

- Log can co context toi thieu: module, action, error code/message.
- Khong log secret, token, raw cookie, file content rieng tu.
- UI loi can co thong bao de nguoi dung biet buoc tiep theo.
- Loi pipeline upscale can giu command/result can thiet de QA tai hien.
